💡 How Does Blockchain Tamper Detection Work?

1. Local Log Generation: User actions generate timestamps and payloads, which get hashed using standard SHA-256.

2. Blockchain Anchoring: The SHA-256 hash is sealed into Ethereum smart contract LogIntegrityV2 across Node 1 & Node 2. It is mathematically immutable.

3. Tamper Exposure: When someone alters even a single character in the local log file, its new SHA-256 hash changes completely (Avalanche effect). The blockchain comparison reveals the mismatch immediately, proving unauthorized alteration!
